# 🚚 Servis Alanı Analizi

## 🎯 Projenin Amacı  
- Depo bazlı optimum servis alanlarının oluşturulması    
- Sipariş verisi ile KPI’ların hesaplanması  
- Analizlerin nüfus bilgileri ve diğer operasyonel verilerle birleştirilmesi.  
- Sonuçların tematik haritalar ve tablolar üzerinden görselleştirilmesi  

---

## 📊 Kullanılan Veriler  
- **Sipariş verisi** → sipariş adedi, müşteri sayısı, ortalama sepet, toplam kâr  
- **Depo verisi** → depo lokasyonları, servis alanı ilişkileri  
- **Yol ağı verisi** → erişim sürelerinin hesaplanması  
- **Demografik veriler** → ilçe / mahalle bazlı nüfus bilgileri  

---

## 🛠️ Kullanılan Teknolojiler  
- **Python** → Pandas, GeoPandas, Matplotlib ,Networkx, Osmnx  
- **PostgreSQL/PostGIS** → veri depolama ve sorgulama  
- **ArcGIS Pro** → tematik haritalar
- **Git & GitHub** → versiyon kontrol ve paylaşım
